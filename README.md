## 📖 Overview

**PulseBeat** is an ultra-premium, interactive music player designed with modern dark luxury aesthetics, glassmorphism, and smooth cinematic transitions. Built entirely without external frameworks, it mimics the immersive experience of top-tier streaming platforms, providing users with a flawless and responsive music playback environment.

## 🚀 Live Demo

Experience the live application here: https://varung-coder.github.io/CodeAlpha_MusicPlayer/

## ✨ Key Features

- **Multi-Language Playlists**: Seamlessly filter and play curated hit songs across Hindi, Malayalam, and Tamil.
- **Cinematic Visualizer**: A dynamic, neon-glowing waveform canvas visualizer that reacts smoothly to audio levels.
- **Realistic Vinyl Physics**: Interactive album artworks centered within a vinyl record design that rotates naturally during playback.
- **Advanced Playback Engine**: Stutter-free playback with smooth progress bar dragging, play/pause, next/previous, shuffle, and repeat functionalities.
- **Premium Micro-Interactions**: Magnetic hover effects, glass reflections, and perfectly synced glow animations.
- **Fully Responsive**: Flawless design execution across desktop, tablet, and mobile platforms.

## 🛠️ Tech Stack

- **HTML5**: Semantic structure and accessible media elements.
- **CSS3**: Custom properties, Flexbox/Grid layouts, glassmorphism filters, and `@keyframes` animations.
- **JavaScript (ES6+)**: Audio API integration, DOM manipulation, custom playback engine, and canvas rendering.

## 📁 Project Structure

```text
CodeAlpha_MusicPlayer/
```

## 🧠 What I Learnt

Building this premium frontend showcase provided incredible insights into:
- **HTML5 Audio API Integration**: Managing media states, buffering, seeking events, and synchronizing timestamps correctly to prevent UI stutter.
- **Advanced CSS Animations**: Crafting smooth, performant `@keyframes` and transitions for complex elements like a rotating vinyl disc and ambient floating backgrounds.
- **Canvas Rendering**: Using the `<canvas>` element and `requestAnimationFrame` to draw dynamic, audio-reactive waveform visualizers.
- **Responsive Architecture**: Ensuring a complex dashboard layout collapses gracefully into a mobile-friendly view without sacrificing the premium feel.

## 🔮 Future Enhancements

- **Local File Support**: Allow users to drag-and-drop their own MP3 files into the player.
- **Lyrics Integration**: Display time-synced lyrics alongside the playing track.
- **Volume Memory**: Remember user volume preferences using `localStorage`.
